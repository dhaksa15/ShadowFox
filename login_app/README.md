# 🐾 PawPal - Pet Adoption & Care App

A beautiful, fun, and engaging Flutter application for pet adoption and care. Connect loving homes with pets in need!

## ✨ Features

### 🏠 Home Screen

- Animated welcome with floating pet emojis
- Real-time pet availability stats
- Quick access to pet categories (Dogs, Cats, Rabbits, Birds)
- Beautiful gradient designs

### 🐕 Pet Dashboard

- Browse featured pets available for adoption
- Detailed pet cards with breed, age, and personality
- Adoption tips and guidance
- Interactive pet details modal

### 🔍 Search & Filter

- Search pets by name or breed
- Filter by category (Dogs, Cats, Rabbits, Birds, Others)
- Real-time search results
- Add pets to favorites

### 👤 Profile Management

- View adoption history and favorites
- Manage account settings
- Track reviews and activity
- Beautiful stats display

### 🔔 Notifications

- Get alerts about new pets
- Adoption request updates
- Shelter visit reminders
- Message notifications

### ⚙️ Settings

- Toggle push notifications
- Email update preferences
- Dark mode support
- Privacy and security settings

### ❓ Help & Support

- Comprehensive FAQ section
- Contact support
- Adoption guidance
- App usage tips

## 🎨 Design Features

- **Playful Color Scheme**: Pink, turquoise, and yellow gradients

- **Pet Emojis**: 🐶 🐱 🐰 🐦 🐹 throughout the app

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (3.10.1 or higher)
- Dart SDK
- Android Studio / VS Code
- iOS Simulator / Android Emulator

### Installation

1. Clone the repository

```bash
git clone <repository-url>
cd pawpal_app
```

2. Install dependencies

```bash
flutter pub get
```

3. Run the app

```bash
flutter run
```
